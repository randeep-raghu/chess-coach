# Chess Coach

Enter a Lichess username, replay the critical moment from your lost games, and find the better move with a coach beside you.

Under development. It currently runs on localhost only.

## Run locally

Requires Node.js 22.12 or newer.

```bash
npm install
npm run dev
```

Then open the URL that Vite prints.

## Commands

| Command | What it does |
| --- | --- |
| `npm run dev` | Starts the app and Worker locally |
| `npm test` | Runs the tests |
| `npm run build` | Type-checks and builds for production |
| `npm run preview` | Serves the production build locally |
